## 26 Oct (Mon) — Stage S0

**Git Version Control & Branching Strategy**

- A branch is essentially a pointer to a specific commit
- Best practice: Create a new branch only after completing a milestone and verifying it works
- This keeps each branch stable and well-tested, making it easy to track progress across stages (S0 → S1 → S2...)
